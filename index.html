    ARCTIC DUEL MANUAL

    北極遊戯の遊び方

    01 / 目的

    相手のライフポイント 8000 を 0 にするか、相手のデッキを尽きさせれば勝利。あなたのルームには招待リンクから友人が参加できます。誰も来ない間はポーラーAIが対戦相手です。

    02 / 召喚

    手札のモンスターを選び、光るモンスターゾーンへ。攻撃表示または守備表示で配置。モンスター1体の召喚・セットは1ターンに1回。

    03 / バトル

    「バトルへ」を押し、自分のモンスターを選択。相手モンスターをクリックして攻撃。相手にモンスターがいなければ、相手プレイヤーへ直接攻撃できます。

    04 / 攻守判定

    攻撃表示同士はATKの高い方が生存し、差が相手LPへ。攻撃 vs 守備はATKがDEFを超えれば破壊、届かなければ攻撃側が差のダメージを受けます。

    05 / 魔法・罠

    魔法は手札から発動、またはセットして次のターンに発動。罠はセットしておくと相手の攻撃時に自動で発動します。伏せカードは相手に正体が見えません。

    06 / 操作

    カードを選択 → アクションボタン、または光るマスをクリック。攻撃時はカードが北極の空へ舞い上がり、敵陣へ突進します。BGM・効果音は右上のスピーカーで切替。
